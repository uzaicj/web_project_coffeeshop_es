# Nombre del proyecto:
Triple Espresso

#Descripción:
Este proyecto consiste en una landing page para una cafetería llamada Triple Espresso.
La página presenta información principal del negocio, como el nombre, un mensaje de bienvenida, horarios de atención y ubicación.
Además, incluye un formulario que permite a los usuarios reservar una mesa ingresando su nombre, número de comensales, fecha y hora, y correo electrónico, así como la aceptación de los términos de uso.
El objetivo del proyecto es practicar la estructura de una página web con secciones claras (header, main y footer) y la creación de formularios funcionales y accesibles.

#En este proyecto se utilizaron las siguientes tecnologías y técnicas:
HTML5 para la estructura semántica del sitio (header, nav, main, section y footer).
CSS3 para el diseño visual de la página, aplicando estilos a textos, fondos, formularios y botones.
Uso de Flexbox para la organización de elementos en el header y el footer.
Aplicación de formularios HTML con distintos tipos de input (text, number, datetime-local, email y checkbox).
Uso de fuentes externas (Google Fonts) para mejorar la tipografía del sitio.
Organización del código con metodología de clases tipo BEM para mantener claridad y orden en los estilos.
